# B 题 — 优化决策

> 规划/调度/配置类问题，核心任务是目标函数+约束求解。

## 题型识别

| 属性 | 值 |
|------|-----|
| 关键词 | 最优、规划、调度、配置、分配、最小成本、资源分配 |
| 核心任务 | 目标函数+约束求解 |
| 推荐算法 | SA-PSO、GA、DE、LP、MIP |
| 模板 | `templates/template-b.md` |

## 细分类

| 细类 | 信号词 | 频率 | 首选算法 |
|------|--------|------|---------|
| OPT 优化 | 最小成本、资源分配、选址、排班 | 最高 | [[SA-PSO混合优化]] / [[遗传算法GA]] / [[差分进化DE]] |
| COM 组合 | TSP、背包、调度 | 高 | DP / GA / PSO |
| GRA 图论 | 网络、路径、覆盖、中心性 | 中 | Dijkstra / Kruskal |

## 六段子结构

1. **参数配置与数据预处理**
2. **基础经典模型**（LP/NLP 完整建模）
3. **传统模型缺陷定量剖析**
4. **自主创新改进模型**（智能优化 + 约束处理）
5. **算法设计与求解**（SA-PSO vs GA vs DE 三算法对比）
6. **数值结果与可视化**+算法对照实验

## 算法组合推荐

```
基础方案：线性规划/非线性规划
创新方案：SA-PSO / GA / DE（三算法对比）
消融对照：基础方案 vs 创新方案
```

## MCP 求解器路由

| API | 功能 | 适用场景 |
|-----|------|---------|
| `solve_linear_program` | 线性规划(LP) | 线性目标+线性约束 |
| `solve_integer_program` | 整数规划(IP) | 整数决策变量 |
| `solve_mixed_integer_program` | 混合整数规划 | 连续+整数混合 |
| `solve_knapsack_problem` | 背包问题 | 选择问题 |
| `solve_vehicle_routing_problem` | VRP | 物流配送 |
| `solve_job_shop_scheduling` | 车间调度 | 生产调度 |
