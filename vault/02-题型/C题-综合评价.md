## 六段子结构

1. **参数配置与数据预处理**
2. **基础经典模型**（AHP + 熵权法 + TOPSIS 完整流程）
3. **传统模型缺陷定量剖析**
4. **自主创新改进模型**（权重融合策略改进）
5. **算法设计与求解**（TOPSIS vs VIKOR vs GRA 对比）
6. **数值结果与可视化**+算法对照实验

## 算法组合推荐

```
权重确定：AHP（主观）+ 熵权法（客观）
综合评价：TOPSIS / VIKOR
关联分析：灰色关联 GRA
```

## 评价类问题核心流程

1. **指标体系构建**：科学性、全面性、可操作性、层次性
2. **数据预处理**：异常值剔除（3σ/箱形图）、标准化
3. **权重确定**：AHP（主观）+ 熵权法（客观）→ 组合权重
4. **综合评价**：TOPSIS 排序 / VIKOR 折中 / GRA 关联度
5. **灵敏度分析**：权重扰动对排名的影响
