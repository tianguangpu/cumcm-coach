# D 题 — 数据分析

> 统计/预测/分类/聚类类问题，核心任务是数据分析与预测。

## 题型识别

| 属性 | 值 |
|------|-----|
| 关键词 | 统计、预测、趋势、相关性、回归、时序、分类、聚类 |
| 核心任务 | 数据分析预测 |
| 推荐算法 | TAM（首选）、ARIMA、MLP、GM(1,1) |
| 模板 | `templates/template-d.md` |

## 细分类

| 细类 | 信号词 | 频率 | 首选算法 |
|------|--------|------|---------|
| PRE 预测 | 时序、回归、分类、异常检测 | 最高 | [[TAM时序分析]] / [[ARIMA预测]] / MLP / [[GM11灰色预测]] |
| STA 统计 | 概率、置信、抽样、排队 | 中 | Monte Carlo |
| CLU 聚类 | 聚类、分组、降维、画像 | 中 | K-Means / 层次聚类 |
| NLP 文本 | 文本、摘要、相似、主题 | 低 | TF-IDF + 余弦 / LDA |

## 六段子结构

1. **参数配置与数据预处理**
2. **基础经典模型**（TAM/ARIMA 完整建模）
3. **传统模型缺陷定量剖析**
4. **自主创新改进模型**（多算法融合/特征工程）
5. **算法设计与求解**（TAM vs ARIMA vs MLP vs GM(1,1) 四算法对比）
6. **数值结果与可视化**+算法对照实验

## 算法组合推荐

```
时序预测：TAM(首选) + ARIMA + BP 神经网络 + GM(1,1)
交叉验证：四算法对比取最优
检验：拟合精度 + 蒙特卡洛
```
