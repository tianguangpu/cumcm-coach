# 数据驱动优化决策 Playbook

> 来源：Lupynow/math-modeling-skills (196★)，MIT 授权。
> 题型：C 题（大数据/经管/运筹优化）

## 匹配条件

- 特征词：种植策略、农作物优化、补货决策、定价策略、预测+优化、随机优化、鲁棒优化
- 数学本质：时间序列预测 + 多约束混合整数规划 + 随机/鲁棒优化 + 风险量化

## 典型题目

- 2024 C 题：农作物种植策略优化（12 约束 + CVaR + DEGA 算法）
- 2023 C 题：蔬菜类商品自动定价与补货决策（LSTM + PSO/NSGA-II）
- 2021 C 题：生产企业原材料的订购与运输
- 2020 C 题：银行对中小微企业的信贷决策

## 解题路径

### Step 1：数据预处理与多维度可视化

标准流程：
1. 多表自然连接（NJ）：按主键 merge
2. One-hot 编码分类变量
3. 时间序列化：按日/周/月/年聚合
4. 异常值清洗：3σ 法则
5. 缺失值处理

可视化三板斧：双重饼图 + 分组条形图 + 边际收入排名表

### Step 2：确定性优化模型

决策变量：连续变量 X + 二元变量 Y，大 M 法连接

### Step 3：时间序列预测

ACF 周期判定 + 时间序列分解（趋势+季节+残差）
