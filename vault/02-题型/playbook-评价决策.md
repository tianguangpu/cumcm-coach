# 评价 + 决策问题 Playbook

> 来源：Lupynow/math-modeling-skills (196★)，MIT 授权。
> 题型：C 题（大数据/经管类）

## 匹配条件

- 特征词：信贷风险、信用评价、定价策略、补货决策、供应商选择、综合评估
- 数学本质：多指标综合评价 + 多目标规划 / 最优化决策

## 典型题目

- 2020 C 题：银行信贷决策
- 2021 C 题：原材料订购与运输
- 2023 C 题：蔬菜类商品定价与补货
- 2022 C 题：古代玻璃制品成分分析

## 解题路径

### Step 1：指标体系构建

- 科学性：明确数学定义
- 全面性：覆盖主要维度
- 可操作性：数据可计算
- 层次性：树状评价体系

### Step 2：量化方法

- **路径 A**：Logistic 回归（有标签数据）
- **路径 B**：PCA + 熵权法/TOPSIS（无标签数据）
- **路径 C**：BP 神经网络（缺失标签推广预测）

### Step 3：多目标决策

目标函数：净收益最大化 + 最大个体风险最小化
