# GM(1,1) 灰色预测

> 小样本（<20个数据点）条件下的首选预测方法。

## 基本信息

| 属性 | 值 |
|------|-----|
| 类型 | 预测 |
| 适用题型 | [[D题-数据分析\|D 数据]] |
| 代码路径 | `algorithms/prediction/gm11.py` |
| 接口 | `GM11(x0, predict_steps=1)` → 直接返回预测值 |
| 适用条件 | 小样本(<20)，单调趋势 |

## 算法原理

1. 累加生成（AGO）：x⁽¹⁾(k) = Σx⁽⁰⁾(i)
2. 建立微分方程：dx⁽¹⁾/dt + ax⁽¹⁾ = b
3. 求解参数 a, b（最小二乘）
4. 还原预测值

## 使用示例

```python
from algorithms.prediction.gm11 import GM11

x0 = [100, 120, 150, 180, 220]  # 原始数据
forecast = GM11(x0, predict_steps=3)  # 预测未来3步
print(f"预测值: {forecast}")
```

## 局限性

- 仅适用于单调趋势数据
- 数据波动大时精度下降
- 预测步数越多，误差越大
