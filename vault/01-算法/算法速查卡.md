## 算法组合推荐

### B 优化题标准组合
```
基础方案：线性规划/非线性规划
创新方案：SA-PSO / GA / DE（三算法对比）
消融对照：基础方案 vs 创新方案
```

### C 评价题标准组合
```
权重确定：AHP（主观）+ 熵权法（客观）
综合评价：TOPSIS / VIKOR
关联分析：灰色关联 GRA
```

### D 数据题标准组合
```
时序预测：TAM(首选) + ARIMA + BP 神经网络 + GM(1,1)
交叉验证：四算法对比取最优
检验：拟合精度 + 蒙特卡洛
```
