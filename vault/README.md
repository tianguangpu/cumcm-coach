# v7 Obsidian 知识库

> cumcm-coach-skill v7.10.0 的 Obsidian 知识系统。

## 使用方法

1. 打开 Obsidian
2. 选择「打开另一个库」→「打开文件夹作为库」
3. 选择 `~/.claude/skills/cumcm-coach-skill-v7/vault/` 目录
4. 开始浏览
