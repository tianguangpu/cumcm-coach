# 模型升级路径

> 从基础模型到创新模型的升级路线。

## 升级路线

```
基础方案（经典模型）
  ↓ 定量缺陷分析
改进方案（优化参数/结构）
  ↓ 消融验证
创新方案（混合算法/新方法）
  ↓ 基线比较
论文方案（最优组合）
```

## 各题型升级路径

### B 优化题
```
LP/NLP → GA → SA-PSO → 混合策略（GA+SA+局部搜索）
```

### C 评价题
```
等权 TOPSIS → AHP+TOPSIS → AHP+熵权+TOPSIS → VIKOR/GRA 对照
```

### D 预测题
```
移动平均 → ARIMA → TAM → TAM+ARIMA+MLP+GM(1,1) 四算法融合
```

### A 机理题
```
解析解 → FDM → FDM+网格收敛性 → FEM/FVM（复杂几何）
```
