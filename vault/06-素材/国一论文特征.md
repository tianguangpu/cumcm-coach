- 质量守恒 + Ronge-Kutta + 分段求解（2019A 高压油管）
- 多目标规划 + NSGA-II + 灵敏度（2024B 生产决策）
- 几何光学 + 有限差分 + 优化（2023A 定日镜场）
- 沿程变传热系数 K(x) + 阶梯间隙 Ta（2020A 炉温曲线，R²=0.9994）
