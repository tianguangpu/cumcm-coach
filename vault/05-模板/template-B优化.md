# B 题论文模板（优化决策）

> CUMCM B 题专用模板，Typst + LaTeX 双引擎。

## 模板文件

- LaTeX：`templates/template-b.tex`
- Typst：`templates/template-b.md`

## 结构

```
§1 问题重述
§2 问题分析
§3 模型假设
§4 符号说明
§5 模型建立与求解
  5.X.1 参数配置与数据预处理
  5.X.2 基础经典模型（LP/NLP）
  5.X.3 传统模型缺陷定量剖析
  5.X.4 自主创新改进模型（智能优化）
  5.X.5 算法设计与求解（SA-PSO vs GA vs DE）
  5.X.6 数值结果与可视化
§6 模型检验
§7 模型评价与推广
§8 参考文献
§AI工具使用声明
§附录
```
