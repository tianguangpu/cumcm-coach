# A 题论文模板（机理建模）

> CUMCM A 题专用模板，Typst + LaTeX 双引擎。

## 模板文件

- LaTeX：`templates/template-a.tex`
- Typst：`templates/template-a.md`

## 结构

```
§1 问题重述
  1.1 问题背景
  1.2 要解决的问题
§2 问题分析
  2.1 整体思路
  2.2 子问题划分
§3 模型假设
§4 符号说明
§5 模型建立与求解
  5.1 问题一
    5.1.1 参数配置与数据预处理
    5.1.2 基础经典模型
    5.1.3 传统模型缺陷定量剖析
    5.1.4 自主创新改进模型
    5.1.5 算法设计与求解
    5.1.6 数值结果与可视化
  5.2 问题二（同结构）
  ...
§6 模型检验（四重检验）
§7 模型评价与推广
§8 参考文献
§AI工具使用声明
§附录
```
