# 论文自审框架

> 交付前四轮系统性自审，替代简单的排版检查清单。
> 来源：Lupynow/math-modeling-skills (196★)，MIT 授权。

## 使用时机

论文全文完成后、最终交付前，按顺序执行四轮审查。每轮通过后才进入下一轮。

## 第一轮：论证逻辑审查

### Claim-Evidence 映射表

| # | Claim（主张） | Evidence（证据位置） | Type | Status |
|---|-------------|-------------------|------|--------|
| 1 | 核心结论 | 图表/表格/公式 | main | ✅/⚠️/❌ |
| 2 | 模型 X 优于 Y | 对比实验+统计检验 | comparison | ✅/⚠️/❌ |
| 3 | 参数 λ 不敏感 | 灵敏度分析图 | sensitivity | ✅/⚠️/❌ |

### Claim 类型

| 类型 | 含义 | 需要什么证据 |
|------|------|------------|
| `main` | 核心结论 | 多个子问题交叉验证 |
| `comparison` | 模型对比 | 统计检验+多数据集 |
| `mechanism` | 因果关系 | 消融实验或因果推断 |
| `sensitivity` | 参数敏感性 | 灵敏度分析图/表 |
| `boundary` | 适用范围 | 边界测试 |
| `innovation` | 创新点 | 与现有方法的可量化差异 |
