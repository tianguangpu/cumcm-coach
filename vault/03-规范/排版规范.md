# 排版规范

> 对齐国赛优秀论文 B159 的排版标准。

## 核心要求

| 项目 | 要求 |
|------|------|
| 行距 | 1.5 倍 |
| 首行缩进 | 2 字符 |
| 章节标题 | 一级居中，二三级左对齐 |
| 目录 | **删除**（2024 规范要求不要目录） |
| 页眉 | 空 |
| 页脚 | 页码居中 |

## LaTeX 模板

- `templates/template-{a,b,c,d}.tex`（LaTeX 格式）
- `templates/template-{a,b,c,d}.md`（Typst 格式）

## 字体规范

| 元素 | 字体 |
|------|------|
| 中文正文 | SimSun（宋体） |
| 中文标题 | SimHei（黑体） |
| 英文/数字 | Times New Roman |
| 代码 | Consolas |

## 图表编号

- 图：`图 1`, `图 2`, ...
- 表：`表 1`, `表 2`, ...
- 公式：`(1)`, `(2)`, ...
