# 图型路由规范 v1.0

> v7 第 3 步「图表生成」的图型→工具路由总表。执行时按此分流，禁止凭直觉选工具。

## 三级路由总览

```
出图前选型 ── diagram-master（题型→40类图型清单）
       │
       ├─ 概念图/流程图 ── diagram-design（HTML+SVG）/ Mermaid
       │                    └─ 遵循 flowchart-specs.md 灰度规范
       │
       ├─ 常规数据图 ──── figure-skill（Python）/ figure-specs.md 10技法（MATLAB）
       │
       └─ 惊艳高级图 ──── nature-plot-repro（首选，MATLAB 26案例）
                            └─ mathmodel-figure-templates（兜底，Python 11模板）
```

## 路由决策树

1. **流程/结构/路线？** → 概念图 → `diagram-design`（灰度无彩色）
2. **常规统计图？** → 常规图 → `figure-skill` / `figure-specs.md`
3. **新颖高级图？** → 惊艳图 → `nature-plot-repro`（MATLAB）/ `mathmodel-figure-templates`（Python）

## 惊艳高级图映射

| 图型 | 首选工具 | 兜底（Python） | 适用场景 |
|------|---------|----------------|---------|
| 弦图 | nature-plot-repro | figure-templates | 多对多关联 |
| 桑基图 | nature-plot-repro | figure-templates | 能量流/资金流 |
| 泰勒图 | nature-plot-repro | figure-templates | 预测模型对比 |
| 环形热图 | nature-plot-repro | figure-templates | 分组时序热图 |
| 小提琴图 | nature-plot-repro | figure-templates | 分布对比 |

## 触发词速查

- 「流程图/技术路线/模型结构」→ `diagram-design`
- 「弦图/桑基/泰勒/环形热图/小提琴」→ `nature-plot-repro`
- 「SHAP/山脊图/蜂群图」→ `mathmodel-figure-templates`
- 「Nature同款/顶刊风格」→ `nature-plot-repro`
