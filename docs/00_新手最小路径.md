# 新手最小路径（72 小时赛，3 页看完）

> 本仓库东西很多（36 算法 + 30 脚本 + 8 MCP + 4 级评审），但**你只需要用到其中一小部分**。

## 一、3 步核心路径

### 第 1 步：判断题型（30 秒）

看题目关键词，对号入座：

| 题型 | 关键词 | 核心做法 |
|------|--------|---------|
| **A 机理** | 物理 / 几何 / 轨迹 / 能量 / 扩散 | 建机理方程 → 数值解 |
| **B 优化** | 最优 / 规划 / 调度 / 分配 | 目标函数 + 约束 → 求解 |
| **C 评价** | 评价 / 决策 / 排序 / 指标 | 指标体系 → 综合评价 |
| **D 数据** | 统计 / 预测 / 趋势 / 回归 | 数据建模 → 预测 |

### 第 2 步：套模板 + 选高频算法

用 `templates/template-{题型}.tex` 起论文骨架，配下面「高频算法」选型。

### 第 3 步：交卷前跑 L1 检查

```bash
python scripts/auto_check.py --paper paper/main.tex --level 1
```

查 5 个硬伤：**页数超限、AI 声明位置、数值一致性、附录代码完整、图题含结论**。这是交卷前真正能救命的检查。

## 二、高频算法（只需记这 12 个）

| 题型 | 算法 | 何时用 |
|------|------|--------|
| B 优化 | LP / MIP（`solver_router.py`）| 线性 / 整数规划 |
| B 优化 | SA-PSO / GA / DE | 连续 / 非线性优化 |
| C 评价 | AHP + 熵权 + TOPSIS | 综合评价排序 |
| C 评价 | VIKOR / 灰色关联 | 多准则折中 |
| D 数据 | ARIMA / GM(1,1) | 时序预测 |
| D 数据 | 回归 / 聚类 | 关系 / 分组 |
| 通用 | Monte Carlo | 不确定性刻画 |
| 通用 | Sobol / 假设误差 | 灵敏度 / 检验 |

> 真题高频的就这十来个。其余 20+ 算法（SIR/SEIR、博弈纳什、FEM 等）几年不出一题，需要时再查 `algorithms/hmml_index.md`。

## 四、一句总结

你的 72 小时应该花在**建模 + 写作**上，不是学工具。

这个工具真正帮你解决两件事：
1. **选对方法**（题型识别 → 模板/算法路由）—— 新手最懵的就是「这题该用啥」；
2. **交卷前不踩硬伤**（L1 自动化检查）—— 页数、AI 声明、数值溯源、附录代码。

其余的，需要时再回来翻。
