## 一份报告长什么样
跑：
```bash
python scripts/profile_data.py results.csv --group group --group condition
```
输出有四个核心区块：
1. **Columns** — 每列的类型、样本量、缺失率、关键统计
2. **Group structure** — 分组样本量的最小/中位/最大
3. **Correlations** — 数值列之间的 Pearson r（按 |r| 排序）
4. **Warnings + Chart suggestions** — 自动提示与初步图型建议

---

## 列类型识别规则
| 类型 | 识别规则 | 画图含义 |
|---|---|---|
| `continuous` | numeric dtype，唯一值 > 7 或包含小数 | y 轴默认走它 |
| `ordinal` | numeric dtype，唯一整数值 ≤ 7 | 横轴可走，但**别连折线** |
| `categorical` | object 或 categorical dtype，唯一值 ≤ 30 | x 轴 / hue 走它 |
| `boolean` | bool dtype 或全 0/1 | 拆成 2 组对比 |
| `datetime` | datetime dtype | 时间轴；折线首选 x |
| `text` | object dtype，唯一值多 | 一般是 ID/笔记类，**不画** |

**坑**：列类型自动识别有时会错。跑完报告后**先看类型识别对不对**，错了立刻在数据里改类型再重跑。

## 样本量的影响
| 每组 n | 该用什么图 | **不能**用什么图 |
|---|---|---|
| n < 3 | **直接列每个点**（dot plot） | 均值柱状、箱线、小提琴 |
| 3 ≤ n < 10 | stripplot / 蜂巢散点 / dot plot | 均值柱状；箱线慎用 |
| 10 ≤ n < 30 | **箱线 + 叠加 stripplot** | 仅画均值柱状（**严禁**） |
| n ≥ 30 | 箱线 / 小提琴 / 带误差柱 都可 | — |

看到 "WARN: at least one group has n<10" → 立刻把图型从"均值柱"切到"箱线 + stripplot"。

## 分布形态的影响
| skew | 含义 | 决策 |
|---|---|---|
| \|skew\| < 0.5 | 大致对称 | 均值 ± SD 可信 |
| 0.5 ≤ \|skew\| < 1 | 中度偏 | 优先**中位数 ± IQR** |
| \|skew\| ≥ 1 | 高度偏 | 必须箱线/小提琴；考虑**对数变换** |

跨量级 → 对数轴：变量最大值/最小值 > 100，且全正。

异常值处理三选一（必须在图注交代选择）：
1. **展示**：画出来，让读者看到分布全貌
2. **标注**：保留但加 annotation 说明
3. **剔除**：必须有明确的方法学理由

---

## 分组结构的影响
| 分组维度 | 映射建议 |
|---|---|
| 单维度 | x 轴 |
| 双维度 | x 轴 + hue 颜色 |
| 三维度 | x 轴 + hue + 子图（facet） |
| 四维度+ | **拆图**或选子集 |

---

## 相关性 / 多重共线性的提示
- **高度相关的列**（|r| > 0.7）——散点时不要俩都做 x 轴或都做 hue
- **辛普森悖论**：整体相关 vs 分组内相关方向相反——画散点必须分组着色看
- **非线性相关**：Pearson 只测线性，看到 r=0.1 别下"无关"结论

---

## 缺失值与异常值
| 缺失率 | 处理 |
|---|---|
| < 5% | 默认忽略；画图时 dropna 即可 |
| 5-20% | 在图注里交代 |
| > 20% | **不能默默忽略** |

---

## 从报告到画图决策的流程
```
profile_data.py 输出报告
        ↓
1. 看 Columns 区：类型对不对？
   → 错的列回去 .astype(...) 修
        ↓
2. 看 Group structure：样本量够吗？
   → n<10 警告 → 切到箱线+stripplot
        ↓
3. 看偏度：
   → skew>1 → 箱线/小提琴 + 考虑 log 轴
        ↓
4. 看维度组合数：
   → >12 → 拆图
        ↓
5. 看 Correlations：
   → 决定散点 hue/style 配置
        ↓
6. 看 Warnings：每条都处理掉
        ↓
查 chart_selection.md 定最终图型
```
