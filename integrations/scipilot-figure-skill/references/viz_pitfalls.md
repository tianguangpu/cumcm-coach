## P1. 均值柱状图掩盖分布与样本量
**错误**：每组只画一根柱代表均值，加一条小误差棒，没有原始数据点。
**审稿人视角**：
- n=3 和 n=300 画出来一样高，无法判断证据强度
- 双峰分布、严重偏态、单个 outlier 主导——全被均值吃掉
- 2020 年起多家期刊公开呼吁停止使用"裸均值柱"
**正确做法**：
1. n ≥ 10 → **箱线/小提琴 + 叠加 stripplot 显示原始点**
2. n < 10 → **直接 stripplot / dot plot**，根本不画统计柱
3. 一定要用柱状 → 至少**叠加 stripplot**，且必须显示误差棒

## P2. 双 Y 轴的误导性
**错误**：左 y 轴一组数据、右 y 轴另一组数据，画在同一张图上。
**审稿人视角**：两个轴的尺度可以任意调，视觉上的"重合"或"分歧"完全是作图者捏造的
**正确做法**：
1. 两个变量量纲相同 → 共用一个 y 轴
2. 量纲不同但要看相关 → 散点图
3. 量纲不同要看趋势 → **拆成上下两个子图**，共享 x 轴；或**标准化**两个量到 [0,1] 后共轴

## P3. 饼图与 3D 图
**错误**：用饼图展示占比；用 3D 柱状/3D 饼/3D 表面图。
**正确做法**：
1. 占比 → **横向柱状图**（按值排序，类别名在 y 轴）
2. 总和分解 → 堆叠柱状（单根或多根）
3. 需要展示 3D 数据 → **2D 热力图** + colorbar；或 contour plot

## P4. Y 轴不当截断
**错误**：y 轴从一个非 0 的值开始，让小差异看起来很大。
**正确做法**：
1. y 是比例/概率/准确率 → **从 0 开始**
2. y 跨数量级 → **log 轴**而不是截断线性轴
3. 必须截断 → **明确画一道断裂标记**，并在图注说明

## P5. 连续色阶无 colorbar
**错误**：用颜色深浅映射连续值，但没画 colorbar。
**正确做法**：
1. 任何用颜色映射数值的图 → **必须配 colorbar**
2. colorbar 必须有 **label**（变量名 + 单位）
3. 多张图比较时 → **锁定** `vmin` / `vmax` 一致

## P6. 把离散点连成折线
**错误**：x 是分类变量，却用 `plt.plot` 把每组均值用线连起来。
**正确做法**：
1. x 是分类 → 柱状 / 箱线 / 点图（dot plot）
2. x 是有序但离散 → 点图，**可选**用极细的"引导线"连接但要在图注说明
3. x 是真正连续（时间、剂量值）→ 才用折线

## P7. 过度使用颜色
**错误**：一张图里用 10+ 种颜色区分类别；或不同图同一变量用不同颜色。
**正确做法**：
1. 类别 ≤ 5 → 颜色 + 双重编码（线型/marker）
2. 类别 6-12 → 用**直接标注**（曲线末端写名字）
3. 类别 > 12 → 拆图或聚类合并，或用 small multiples
4. **跨图色彩一致性**：建一份 `palette` 字典，所有图共用

## P8. 图例缺失或不清
**正确做法**：
1. 任何 hue 映射必有图例
2. 图例标签是**人话**不是变量名
3. 图例位置不遮挡数据；`frameon=False`

## P9. 误差类型不交代
**错误**：图里有误差棒/阴影带/箱线，但图注里没写是 SD/SEM/95% CI。
**正确做法**：图注必须包含误差类型、n、检验方法、符号定义。

## P10. 过度装饰（chartjunk）
**正确做法**：
1. 关掉默认网格或只保留主网格、虚线浅灰
2. 去掉顶/右两条 spine（`despine`）
3. 同类数据**用同一颜色**

## P11. 分辨率 / 格式不达标
**正确做法**：
1. 数据图 → **矢量** PDF / SVG / EPS
2. 照片 → **位图** PNG / TIFF，**≥300 DPI**
3. 永远不用 JPEG
4. PDF 嵌入 TrueType 字体（fonttype 42）

## P12. 一图多论点
**错误**：一张图里塞了 5 个 panel，每个想说不同的事。
**正确做法**：
1. 一张图 → 一个核心结论
2. 想说多件事 → 拆成多张图或多个 panel

## P13. 红绿对比、不做色盲检查
**正确做法**：
1. 用 **Okabe-Ito** 或 seaborn `colorblind` 调色板
2. 不同类别**加冗余编码**：颜色 + 线型/marker
3. 导出灰度版本检查

## P14. rainbow / jet 色图
**错误**：连续值用 `rainbow` / `jet` / `hsv` 色图。
**正确做法**：
- 单向连续值 → `viridis` / `magma` / `inferno` / `cividis`
- 双向数据 → `RdBu_r` / `PiYG` / `seismic` + `center=0`

## P15. 显著性符号滥用
**正确做法**：
1. 只标**与论点有关**的少数几个对比
2. 图注必须写：检验类型 + 校正方法 + 符号定义
3. n<10 的"显著"要谨慎

## P16. 缺字乱码：中文 / 负号 / 特殊符号变方框
**正确做法**：
1. **中文图先配字体**：`setup_style(lang='zh')`
2. **负号方框**：`axes.unicode_minus = False`
3. **导出前程序自检**：`visual_qa.audit_layout(fig)` 拦截缺字

## P17. 文字裁切与图例遮盖
**正确做法**：
1. **从源头**：`setup_style` 默认开 `constrained_layout`
2. **兜底**：`layout_tools.finalize_figure(fig)`
3. **图例移出数据区**：`bbox_to_anchor=(1.02, 1.0)`
4. **终检**：`visual_qa.audit_layout(fig)` 检测文字越界

## P18. 多面板子图编号不对齐
**正确做法**：用 `layout_tools.add_panel_labels(fig)` 统一对齐。
