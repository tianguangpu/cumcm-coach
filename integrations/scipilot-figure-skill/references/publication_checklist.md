## 尺寸 & 分辨率
- [ ] `figsize` 直接设成目标期刊的最终尺寸
- [ ] 导出后**没有**在 Word/LaTeX/PPT 里再缩放
- [ ] 位图 DPI ≥ 300（普通）/ ≥ 600（线条图、IEEE）
- [ ] 用 `check_figure.py` 验证实际尺寸与目标尺寸偏差 < 0.1 in

## 文件格式
- [ ] 数据图 → **矢量** PDF/SVG/EPS
- [ ] 显微图、照片 → **位图** PNG/TIFF（≥300 DPI）
- [ ] **没有任何 JPEG**
- [ ] PDF 嵌入 TrueType 字体（fonttype 42）

## 字体 & 字号
- [ ] 字体与期刊一致
- [ ] 最终尺寸下正文标签 7–9 pt，刻度数字 6–8 pt，**最小字 ≥ 6 pt**
- [ ] 所有字符可读，没有方框
- [ ] 同一张图字体不超过 2 种

## 配色 & 色盲
- [ ] 默认 Okabe-Ito 或 seaborn `colorblind`，**避免红绿对比**
- [ ] 不同类别**双重编码**：颜色 + 线型/marker
- [ ] 导出灰度预览，灰度下仍能区分
- [ ] 热力图用**感知均匀**色图
- [ ] 双向数据用发散色图 + `center=0`

## 坐标轴 & 标签
- [ ] x/y 轴都有 label，包含**变量名 + 单位**
- [ ] 刻度数字精度合理
- [ ] log 轴明确标 log
- [ ] 不出现 `axes.unicode_minus` 方框

## 图例 & 子图标签
- [ ] 图例清晰可读，`frameon=False`
- [ ] 图例位置不遮挡数据
- [ ] 子图标签按期刊格式
- [ ] 多面板的子图字号、配色、坐标尺度**保持一致**

## 误差 & 统计交代
- [ ] 凡有误差棒/阴影区间/箱线 → **图注**必须写明误差类型、n、检验方法、符号定义
- [ ] 显著性标注的位置不遮挡数据
- [ ] 没有"无误差棒的均值柱"

## 语义合规
- [ ] **P1**：n<10/组不**用均值柱状图**
- [ ] **P2**：没有双 Y 轴
- [ ] **P3**：没有饼图，没有 3D 柱/3D 饼/3D 表面
- [ ] **P4**：y 轴起点合理
- [ ] **P5**：所有连续色阶配 colorbar
- [ ] **P6**：x 是分类变量的话没有用折线连组均值
- [ ] **P12**：一张图只讲一个核心结论
- [ ] **P14**：连续值用 viridis/magma/RdBu_r，没有 rainbow/jet

## 中文图额外项
- [ ] `setup_style(lang='zh')` 已调用
- [ ] 中文字体可用
- [ ] 中文 + 数字/西文混排正确
- [ ] 负号显示正确，不是方框
- [ ] 中文期刊 PDF 优先于 EPS

## 终检
- [ ] 跑一遍：`python scripts/check_figure.py figs/* --min-dpi 300 --strict`
- [ ] 把生成的 PDF **打印出来**肉眼看一遍
- [ ] 用色盲模拟工具（Color Oracle / Coblis）查一遍
- [ ] 给非同行看一眼能不能看懂
