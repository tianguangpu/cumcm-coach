# 国一论文特征库

> 收录历年国一论文的结构特征、创新点、图表规范，供赛时参考。
> 来源：GitHub开源项目 + 官方优秀论文

## 国一论文核心特征（从GitHub项目提炼）

### 一、模型结构（递进链路）

**国一标配**：基础模型 → 缺陷分析 → 改进创新 → 量化验证

| 阶段 | 内容 | 国一做法 |
|------|------|----------|
| 基础模型 | 经典方法建模 | 选择最合适的经典方法，不盲目追求复杂 |
| 缺陷分析 | 找出基础模型不足 | 用数据说明缺陷（如误差大、收敛慢） |
| 改进创新 | 提出改进方案 | 有理论依据的改进，非随意修改 |
| 量化验证 | 证明改进有效 | 量化对比（改进幅度≥10%才算显著） |

### 二、公式规范（三段式）

**国一标配**：前置说明 + 公式本体 + 后置拆解

```latex
% 前置说明：解释公式含义
本文采用质量守恒方程描述管道内流体压力变化：

% 公式本体
\begin{equation}
\frac{\partial p}{\partial t} + c^2 \frac{\partial \rho}{\partial x} = 0
\label{eq:continuity}
\end{equation}

% 后置拆解：解释各变量含义
其中，$p$ 为压力（Pa），$\rho$ 为密度（kg/m³），$c$ 为声速（m/s）。
```

### 三、图表规范（自解释）

**国一标配**：图题含结论 + 关键数值

```
❌ 错误示例：
图1 压力变化曲线

✅ 正确示例：
图1 管道压力随时间变化曲线（t=0.5s时压力峰值达120MPa）
```

### 四、四重检验（必须齐全）

| 检验类型 | 国一做法 | 检查要点 |
|----------|----------|----------|
| 拟合精度 | R²/MAE/RMSE/MAPE | R²≥0.95为优秀 |
| 灵敏度分析 | Sobol/OAT | 识别关键参数 |
| 蒙特卡洛 | ≥200次模拟 | 计算置信区间 |
| 假设误差 | ≥3项假设量化 | 说明假设合理性 |

### 五、参考文献规范

**国一标配**：近5年≥50%，外文≥30%，总数≥10篇

## 国一论文案例库

### 案例1：2019A 高压油管的压力控制（国一）

**问题类型**：A题机理类

**模型结构**：
1. 质量守恒方程（基础模型）
2. 三次样条插值（数据处理）
3. Ronge-Kutta算法（数值求解）
4. 解的延拓和分段求解（创新改进）

**创新点**：
- 将连续问题离散化，用数值迭代求解
- 提出分段求解思想，处理非线性问题

**图表亮点**：
- 压力-时间曲线（含峰值标注）
- 误差分布图（含置信区间）

**模型结构**：

## 国一论文自查清单

### 摘要检查
- [ ] 是否包含问题背景（1-2句）
- [ ] 是否包含方法名称
- [ ] 是否包含量化结果（R²/误差/改进幅度）
- [ ] 是否包含关键词（3-5个）

### 模型检查
- [ ] 每问是否有递进链路（基础→缺陷→改进）
- [ ] 公式是否三段式（前置+本体+后置）
- [ ] 创新点是否有量化依据

### 图表检查
- [ ] 图题是否自解释（含结论+数值）
- [ ] 图表是否清晰（字号≥8pt）
- [ ] 图表是否在正文中引用

### 验证检查
- [ ] 是否有拟合精度（R²/MAE/RMSE）
- [ ] 是否有灵敏度分析
- [ ] 是否有蒙特卡洛验证
- [ ] 是否有假设误差量化

### 参考文献检查
- [ ] 总数≥10篇
- [ ] 近5年≥50%
- [ ] 外文≥30%
- [ ] 格式统一（GB/T 7714）
