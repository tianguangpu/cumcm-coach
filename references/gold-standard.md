# 国赛金标准内核详细规范

> 每问强制执行的金标准规范。SKILL.md 中仅列摘要，详细规则见本文档。

## (a) 每问六段子结构 (5.X.1~5.X.6)

```
5.X.1 参数配置与数据预处理
5.X.2 基础经典模型(完整推导+全部公式,三段式绑定)
5.X.3 传统模型缺陷定量剖析(2-3项+仿真数据佐证)
5.X.4 自主创新改进模型(决策变量+目标函数+s.t.全部约束+创新点)
5.X.5 算法设计与求解(3算法评级对比表+选用理由+伪代码)
5.X.6 数值结果与可视化+算法对照实验(多算法对比表+质量效率比Q)
```

递进链路:基础→缺陷→改进→算法对比→数值验证。**创新必须量化百分比**。

## (b) 公式三段式强制规范

1. 前置 1-2 句:物理意义、求解目的、变量输入来源
2. 公式本体:`\begin{equation}` 居中 + 全文连续编号 (1)(2)(3)...
3. 后置 1-3 行:逐项拆解、适用边界、对比传统模型精度提升

排版要求:
- 变量 TNR 斜体,向量 `\mathbf{}` 加粗,单位不写入公式
- **禁止中文下标**,全部英文缩写
- `\DeclareMathOperator{\erf}{erf}` `\DeclareMathOperator{\sgn}{sgn}`
- `\begin{align}` 多行约束对齐
- 推导衔接:"基于式(1)结果代入式(2),联立得式(3)";核心公式放正文,冗长推导入附录3

## (c) 四重检验量化模块

| 模块 | 内容 | 配套图 |
|------|------|--------|
| 6.1 拟合精度 | R²/MAE/RMSE/MAPE + 残差正态性 | 残差直方+Q-Q图 |
| 6.2 灵敏度 | **Sobol 全局灵敏度**(S1+ST+95%CI)优先;可补充单参数±10%/±20% 龙卷风图 | Sobol 柱状图 + 龙卷风图 |
| 6.3 蒙特卡洛 | ≥200次 + 均值/标准差/CV/95%CI | MC直方图+CDF |
| 6.4 假设误差量化 | **≥3 项**关键假设逐项量化(每项含风险等级:致命/显著/轻微/可忽略) | 假设风险分级表 + 多子图组图 |

配套脚本:
- 6.1 `algorithms/validation/metrics.py`
- 6.2 `algorithms/validation/sobol.py` / `sobol_enhanced.py`
- 6.3 `algorithms/validation/monte_carlo.py`
- 6.4 `algorithms/validation/assumption_error.py`

## (d) 算法对比表

**B 优化题强制要求**:对比表必须含 ≥1 个 pso_variants.py 高级部件(Clerc-PSO / TVAC-PSO / PSO+局部搜索 / GA+SA)。

```
| 算法 | 收敛迭代 | 最优值 | 稳定性(CV) | 时间(s) | 评级 |

| Clerc-PSO | 89 | 54.5 MW | 1.8% | 142 | ★★★★ |
| GA | 215 | 52.8 MW | 5.1% | 245 | ★★☆ |
```

## (e) 摘要三段式

- 第一段(1-2行):行业背景极度精简 + 研究对象 + 三层框架概括
- 第二段(核心):各问依次:模型+算法+精准量化结果,数值前置
- 第三段(2-3行):3项创新 + 四重检验指标 + 跨行业迁移
- 关键词:5个空格分隔(对象+模型+算法+方法+指标)

## (f) 附录三模块

1. 附录1:数据说明 + result 样表(5行样例,8列字段)
2. 附录2:全套代码 + 模块说明(每个脚本:输入/输出/功能)
3. 附录3:核心公式完整推导(正文只放结论)

## (g) 消融对比强制

每问 Qi 必须给出「基础方案 vs 创新方案」双方案对照:
- 基础方案(经典模型/常规算法)先立基准数值
- 创新方案(改进模型/组合算法)再量化超越(精度提升 X% / 收敛快 Y%)
- 结果写入 `results/ablation.csv`
- 正文 §5.X.5 算法对比表直接引用 ablation.csv 数值

## (h) 决策日志

每个项目强制创建 `state/decision_log.json`,核心字段:
- team: 队伍信息
- type_assessment: 题型判定
- current_stage: 当前阶段
- per_qi: 每问状态
- change_log: 变更追踪
- propagation_map: 传播地图
- gate_results: 门禁结果

## (i) 分位锚定自评

总分 = Σ(Qi得分 × Qi权重 × 题型权重) / Σ(Qi权重 × 题型权重)
- 国一 ≥82
- 国二 ≥72
- 省一 ≥62

注意:这是 59 份公开样本的经验分位,非官方评分线。
