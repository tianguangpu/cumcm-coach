## 解题示例（一种可行路径）

### Step 1：数据预处理与指标体系构建

评价类问题的核心是"用什么指标来评"：

- **科学性**：指标有明确的数学定义和经济/物理含义
- **全面性**：覆盖评价对象的主要维度
- **可操作性**：从附件数据中可以直接或间接计算得出
- **层次性**：一级指标下设二级指标，形成树状评价体系

数据预处理标准流程：
1. 剔除作废/无效记录
2. 箱形图 + 3σ / 4σ 法则剔除异常值
3. 负值处理
4. 时间维度的聚合

### Step 2：信贷风险 / 综合得分的量化

三种主流路径：

**路径 A -- Logistic 回归模型（有标签数据）**

ln(p_i/(1-p_i)) = β_0 + β_1*x_1i + ... + β_m*x_mi

**路径 B -- PCA + 熵权法 / TOPSIS（无标签数据）**

用 PCA 降维提取主成分，以方差贡献率为权重计算综合得分

**路径 C -- BP 神经网络（缺失标签的推广预测）**

以问题一数据为训练集，预测问题二中缺失的标签

### Step 3：多目标决策模型的建立

目标函数：
- max Σ [r_i - (1-p_i)] * x_i（净收益最大化）
- min max{(1-p_i) * x_i}（最大个体风险最小化）

约束条件：
- 总额度约束：Σ x_i ≤ TotalCredit
- 单项上下界
- 客户流失率约束

### Step 4：缺失数据的补全与模型推广

- **欧氏距离匹配法**：计算到各等级中心的距离，归入最近的等级
- **BP 神经网络预测**：以问题一数据为训练集

### Step 5：突发因素/情景调整

- 对企业/商品按行业、类型进行精细化分类
- 量化突发事件的影响方向和程度
- 用影响系数修正评价指标或约束参数

### Step 6：结果分析与灵敏度检验

- 对比最优策略与"平均情况"的收益差异
- 对关键参数进行灵敏度分析

## 关键陷阱

1. **指标冗余与共线性**：必须先做相关系数矩阵，必要时合并或删减指标
2. **风险与收益的量纲不统一**：需要先做归一化处理
3. **忽略客户流失率**：利率提高会导致客户流失
4. **异常值未处理或过度处理**：不处理会扭曲指标，过度处理会丢失信息
5. **缺失数据补全缺乏验证**：需要留出验证集检验预测准确率

## 完整例题：2020 国赛 C 题 -- 银行对中小微企业的信贷决策

### 结果解读
- 问题一：123 家企业的守约率分布在 0.25~0.94 之间
- 问题二：302 家企业经信誉预测后套用问题一模型
- 问题三：新冠疫情对服务业负面影响大，对医疗/物流正面影响大

### 论文亮点
- "风险量化"转化为"守约率估计"，再嵌入收益函数
- 构造了 6 个有经济学含义的复合指标
- 三个子问题的递进处理：降维思路统一，代码高度复用
