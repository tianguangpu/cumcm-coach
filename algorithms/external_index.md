## 📝 使用建议

1. **优先使用 v7 内置算法**：已针对国赛优化，接口统一
2. **补充使用外部算法**：当需要更多算法对比时，从外部库调用
3. **代码参考**：外部库的代码注释详细，适合学习算法原理
4. **双语言支持**：每个算法都有 Matlab 和 Python 两个版本

## 🎯 题型→算法速查表

### A 机理题
- 传染病模型、人口模型、战争模型
- 有限差分（v7 内置）

### B 优化题
- 线性/非线性/整数/多目标规划
- 模拟退火、粒子群、遗传算法
- Dijkstra、Floyd 最短路径

### C 评价题
- TOPSIS、DEA、AHP、熵权法
- 模糊综合评价、灰色关联分析

### D 数据题
- ARMA、BP 神经网络、灰色预测
- K-means、层次聚类
- PCA、T-SNE、UMAP 降维
- 相关性分析、异常值检测
