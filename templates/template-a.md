## 三、机理建模规范

### 3.1 物理方程三段式模板

```latex
% === 前置说明 ===
太阳光线经定日镜反射后汇聚于吸热塔顶端吸热口，
反射过程遵循菲涅尔反射定律，需建立光线追踪模型。

% === 公式本体 ===
\begin{equation}
\mathbf{r}_{\text{out}} = \mathbf{r}_{\text{in}} - 2(\mathbf{r}_{\text{in}} \cdot \mathbf{n})\mathbf{n}
\label{eq:reflection}
\end{equation}

% === 后置拆解 ===
其中 $\mathbf{r}_{\text{in}}$ 为入射光线单位向量，
$\mathbf{r}_{\text{out}}$ 为反射光线单位向量，
$\mathbf{n}$ 为镜面法向量。式(1)表明反射光线关于法向量对称，
需进一步计算吸热口截获效率。
```

### 3.2 微分方程规范

```latex
% 常微分方程组
\begin{align}
\frac{dx}{dt} &= v_x(t) \label{eq:ode1}\\
\frac{dy}{dt} &= v_y(t) \label{eq:ode2}\\
\frac{dz}{dt} &= v_z(t) - g \label{eq:ode3}
\end{align}

% 初始条件
\begin{equation}
x(0) = x_0, \quad y(0) = y_0, \quad z(0) = z_0
\label{eq:ic}
\end{equation}
```

## 五、结果可视化规范

### 5.1 3D 曲面图（技法1）

```matlab
% 3D曲面 + 底面等高线投影
[X,Y] = meshgrid(linspace(-3,3,80));
Z = peaks(X,Y);

surf(X,Y,Z,'EdgeColor','none','FaceAlpha',0.85);
colormap([0x21,0x66,0xAC; 0.9 0.9 0.9; 0xD6,0x60,0x4D]/255);

% 底面等高线
zmin = min(Z(:));
contour(X,Y,Z,15,'ZData',zmin*ones(size(X)));

% 最值标注
[maxval,imax] = max(Z(:));
plot3(X(idx),Y(idx),Z(idx),'rp','MarkerSize',12);
text(X(idx),Y(idx),Z(idx)+0.3,sprintf('峰值 %.2f',maxval));
```

### 6.2 误差传递公式

```latex
设输入参数误差为 $\delta p_i$，输出误差为 $\delta y$，
根据误差传递公式：
\begin{equation}
\delta y = \sqrt{\sum_{i=1}^{n} \left(\frac{\partial y}{\partial p_i}\delta p_i\right)^2}
\label{eq:error_prop}
\end{equation}
```
